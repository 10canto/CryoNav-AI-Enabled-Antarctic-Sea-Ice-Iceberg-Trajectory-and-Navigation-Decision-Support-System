This document defines all data structures, schemas, and type definitions used
throughout the CryoNav AI application.

================================================================================
NAVIGATION DATA (Primary Data Model)
================================================================================

COMPLETE NAVIGATION DATA OBJECT
--------------------------------
Returned by API and used throughout application:

{
  time: String,                    // ISO 8601 or custom format
  shipPosition: [Number, Number],  // [latitude, longitude]
  
  riskAssessment: {
    status: String,                // 'SAFE' | 'CAUTION' | 'WARNING' | 'EMERGENCY'
    iceConcentration: Number,      // 0-100 (percentage)
    nearestIceberg: Number,        // Distance in km
    nearestIcebergName: String,    // Iceberg identifier
    collisionRisk: Number,         // 0-100 (percentage)
    temperature: Number,           // Celsius
    windSpeed: Number,             // km/h
    windDirection: String,         // Cardinal direction (N, NE, E, etc.)
    windDegrees: Number,           // 0-360 degrees
    visibility: String,            // Descriptive text
    alertTriggered: Boolean        // Emergency alert flag
  },
  
  icebergs: [                      // Array of iceberg objects
    {
      id: String,                  // Unique identifier
      name: String,                // Display name
      position: [Number, Number],  // [latitude, longitude]
      sizeMeters: Number,          // Approximate size
      length: Number,              // Length in meters
      width: Number,               // Width in meters
      detectedAgo: String,         // Time since detection
      confidence: Number,          // 0-100 (detection confidence)
      driftSpeedKnots: Number,     // Drift speed
      driftHeading: Number         // Drift direction (0-360 degrees)
    }
  ],
  
  routes: [                        // Array of route options
    {
      id: String,                  // 'safest' | 'fastest' | 'fuel'
      name: String,                // Display name
      type: String,                // Route type
      color: String,               // Hex color code
      style: String,               // 'solid' | 'dashed' | 'dotted'
      width: Number,               // Line width in pixels
      distanceKm: Number,          // Total distance
      timeHours: Number,           // Estimated time
      timeDays: Number,            // Estimated time in days
      fuelLiters: Number,          // Fuel consumption
      riskPercent: Number,         // 0-100 risk rating
      stars: Number,               // 1-5 star safety rating
      isSafest: Boolean,           // Safest route flag
      isFastest: Boolean,          // Fastest route flag
      isCheapest: Boolean,         // Fuel-efficient flag
      coordinates: [               // Route waypoints
        [Number, Number]           // [latitude, longitude] pairs
      ]
    }
  ],
  
  explanation: {
    headline: String,              // AI-generated summary
    text: String,                  // Detailed explanation
    recommendation: String,        // Recommended route ID
    confidence: Number             // 0-100 confidence level
  },
  
  iceZones: [                      // Ice concentration zones
    {
      name: String,                // Zone name
      concentration: Number,       // 0-100 percentage
      color: String,               // Hex color code
      fillOpacity: Number,         // 0-1 opacity
      coordinates: [               // Polygon vertices
        [Number, Number]           // [latitude, longitude] pairs
      ]
    }
  ],
  
  windData: [                      // Wind vector field
    {
      position: [Number, Number],  // [latitude, longitude]
      direction: Number,           // 0-360 degrees
      speed: Number                // km/h
    }
  ]
}

RISK ASSESSMENT DATA MODEL
================================================================================

RISK ASSESSMENT OBJECT
-----------------------
{
  status: String,                // Risk level
  iceConcentration: Number,      // 0-100 %
  nearestIceberg: Number,        // Distance in km (null if none)
  nearestIcebergName: String,    // Identifier or null
  collisionRisk: Number,         // 0-100 %
  temperature: Number,           // Celsius
  windSpeed: Number,             // km/h
  windDirection: String,         // N, NE, E, SE, S, SW, W, NW
  windDegrees: Number,           // 0-360 degrees
  visibility: String,            // Text description
  alertTriggered: Boolean        // Emergency flag
}

RISK STATUS LEVELS
------------------
1. SAFE (GREEN)
   - Collision Risk: 0-14%
   - Ice Concentration: <30%
   - Visibility: Excellent (>10 nm)
   - No immediate hazards

2. CAUTION (YELLOW)
   - Collision Risk: 15-39%
   - Ice Concentration: 30-60%
   - Visibility: Moderate (4-10 nm)
   - Icebergs detected nearby

3. WARNING (ORANGE)
   - Collision Risk: 40-74%
   - Ice Concentration: 60-85%
   - Visibility: Poor (1-4 nm)
   - Adverse weather conditions
   - Alert triggered

4. EMERGENCY (RED)
   - Collision Risk: 75-100%
   - Ice Concentration: >85%
   - Visibility: Very poor (<1 nm)
   - Immediate danger
   - Alert triggered
   - Emergency protocols activated

RISK CALCULATION FACTORS
-------------------------
Inputs:
1. Ice concentration percentage
2. Distance to nearest iceberg
3. Iceberg drift vectors
4. Wind speed and direction
5. Visibility conditions
6. Sea state
7. Vessel position relative to hazards

Algorithm:
- Base risk from ice concentration
- Proximity multiplier (inversely proportional to distance)
- Drift vector analysis (collision course detection)
- Weather factor (wind speed, visibility reduction)
- Combined weighted score → percentage

================================================================================
WIND DATA MODEL
================================================================================

WIND VECTOR OBJECT
------------------
{
  position: [Number, Number],    // [latitude, longitude]
  direction: Number,             // 0-360 degrees (meteorological)
  speed: Number                  // km/h
}

WIND GRID
---------
- Coverage: Antarctic region (40°S to 75°S)
- Grid spacing: 5° intervals
- Update frequency: Hourly (simulated)
- Data points: ~50-100 vectors

WIND SPEED CATEGORIES
----------------------
0-20 km/h:     Light air (green)
20-35 km/h:    Moderate breeze (yellow)
35-50 km/h:    Strong wind (orange)
50-65 km/h:    Gale force (red)
65+ km/h:      Storm force (dark red)

WIND DIRECTION CONVENTION
--------------------------
Meteorological: Direction wind is coming FROM
- 0° / 360°: North
- 90°: East
- 180°: South
- 270°: West

Prevalent Antarctic Winds:
- Katabatic winds: South to North (downslope from ice sheet)
- Circumpolar westerlies: West to East (40-60°S)
- Polar easterlies: East to West (60-90°S)

================================================================================
DATA VALIDATION RULES
================================================================================

LATITUDE RANGE: -90 to +90 degrees
LONGITUDE RANGE: -180 to +180 degrees

PERCENTAGE VALUES: 0 to 100 (inclusive)

WIND DIRECTION: 0 to 360 degrees (360 === 0)

POSITIVE NUMBERS:
- Distance (km)
- Time (hours, days)
- Fuel (liters)
- Speed (km/h, knots)
- Size (meters)

REQUIRED FIELDS:
- All navigation data fields must be present
- Missing fields use default/null values
- Graceful handling of incomplete data
