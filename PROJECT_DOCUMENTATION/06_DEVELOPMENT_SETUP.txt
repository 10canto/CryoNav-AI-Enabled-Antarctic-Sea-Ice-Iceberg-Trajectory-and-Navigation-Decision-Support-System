================================================================================
                   CRYONAV AI - DEVELOPMENT SETUP GUIDE
================================================================================

This document provides step-by-step instructions for setting up, running, and
developing the CryoNav AI application.

================================================================================
PREREQUISITES
================================================================================

REQUIRED SOFTWARE:
------------------
1. Node.js (v18 or higher)
   - Download: https://nodejs.org/
   - Verify: node --version

2. npm (v9 or higher) or Bun
   - Comes with Node.js
   - Verify: npm --version

3. Git (for version control)
   - Download: https://git-scm.com/
   - Verify: git --version

4. Code Editor (recommended: VS Code)
   - Download: https://code.visualstudio.com/

OPTIONAL SOFTWARE:
------------------
1. Python 3.8+ (for backend, if developing full-stack)
2. Postman or similar (for API testing)
3. Browser DevTools (built into Chrome, Firefox, Edge)

SYSTEM REQUIREMENTS:
--------------------
- Operating System: Windows, macOS, or Linux
- RAM: 4GB minimum, 8GB recommended
- Disk Space: 1GB for project and dependencies
- Internet: Required for initial setup and API features

================================================================================
PROJECT SETUP
================================================================================

STEP 1: CLONE OR DOWNLOAD PROJECT
----------------------------------
If using Git:
```bash
git clone <repository-url>
cd CryoNav-AI-Enabled-Antarctic-Sea-Ice-Iceberg-Trajectory-and-Navigation-Decision-Support-System
cd cryonav-ai
```

If downloaded as ZIP:
- Extract the archive
- Navigate to cryonav-ai folder

STEP 2: INSTALL DEPENDENCIES
-----------------------------
Open terminal in the cryonav-ai directory:

Using npm:
```bash
npm install
```

Using Bun (faster alternative):
```bash
bun install
```

This will install all packages listed in package.json:
- React 19.0.1
- Vite 6.2.3
- Leaflet 1.9.4
- React-Leaflet 5.0.0
- Axios 1.20.0
- Tailwind CSS 4.1.14
- Lucide React 0.546.0
- TypeScript 5.8.2
- And development dependencies

Expected Duration: 2-5 minutes (depending on internet speed)

STEP 3: CONFIGURE ENVIRONMENT (Optional)
-----------------------------------------
Create a .env file (based on .env.example):

```bash
copy .env.example .env  # Windows
cp .env.example .env    # macOS/Linux
```

Edit .env file:
```
VITE_API_BASE_URL=http://localhost:8000
VITE_USE_MOCK_DATA=true
VITE_ENABLE_AUDIO_ALERTS=true
```

Note: The application works without .env as it has built-in defaults.

STEP 4: START DEVELOPMENT SERVER
---------------------------------
```bash
npm run dev
```

Or with Bun:
```bash
bun run dev
```

Expected Output:
```
VITE v6.2.3  ready in 500 ms

➜  Local:   http://localhost:3000/
➜  Network: http://192.168.1.x:3000/
➜  press h + enter to show help
```

STEP 5: OPEN IN BROWSER
------------------------
Navigate to: http://localhost:3000

You should see the CryoNav AI dashboard with:
- Interactive map of Antarctic region
- Ship position marker
- Dashboard panels
- Scenario controls

DEVELOPMENT WORKFLOW
================================================================================

RUNNING THE APPLICATION
-----------------------
Development Mode (with hot reload):
```bash
npm run dev
```
- Changes auto-reload
- Source maps enabled
- Fast refresh
- Port: 3000

Production Build:
```bash
npm run build
```
- Creates optimized bundle
- Output: dist/ folder

Preview Production Build:
```bash
npm run preview
```
- Serves production build locally
- Test before deployment

STOPPING THE SERVER
-------------------
Press: Ctrl+C (or Cmd+C on Mac)

CLEARING CACHE
--------------
If experiencing issues:
```bash
rm -rf node_modules
rm package-lock.json
npm install
```

Or:
```bash
npm run clean  # If clean script exists
```

CONFIGURATION FILES
================================================================================

PACKAGE.JSON
------------
Defines project metadata, dependencies, and scripts.

Key Scripts:
- "dev": Start development server
- "start": Alias for dev
- "build": Create production build
- "preview": Preview production build
- "lint": Run TypeScript type checking

VITE.CONFIG.TS
--------------
Vite build tool configuration.

Key Settings:
- React plugin enabled
- Tailwind CSS integration
- Port: 3000
- Host: 0.0.0.0 (allows network access)
- Build optimizations

TSCONFIG.JSON
-------------
TypeScript compiler configuration.

Key Settings:
- Target: ES2020
- Module: ESNext
- Strict mode enabled
- JSX: react-jsx
- Path aliases (if configured)

INDEX.HTML
----------
HTML entry point.

Includes:
- Root div for React mounting
- Leaflet CSS CDN
- Module script tag for main.tsx
- Meta tags for viewport and charset

CONFIG.JS
---------
Application-level configuration.

Constants:
- API_BASE_URL: Backend server URL
- API_TIMEOUT: Request timeout (10s)
- POLLING_INTERVAL: Data refresh rate (5s)
- SCENARIO_TRANSITION_DELAY: Animation delay (1.5s)
- DEMO_CONFIG: Mock data settings

COMMON DEVELOPMENT TASKS
================================================================================

ADDING A NEW COMPONENT
----------------------
1. Create file in appropriate folder:
   ```
   src/components/Category/NewComponent.jsx
   ```

2. Define component:
   ```javascript
   export default function NewComponent({ prop1, prop2 }) {
     return (
       <div className="new-component">
         {/* Component content */}
       </div>
     );
   }
   ```

3. Import and use in parent:
   ```javascript
   import NewComponent from './components/Category/NewComponent';
   ```

ADDING A NEW API ENDPOINT
--------------------------
1. Define function in api.js:
   ```javascript
   export const getNewData = async () => {
     if (useMockData) return mockNewData;
     try {
       const response = await api.get('/api/new-endpoint');
       return response.data;
     } catch (error) {
       return handleApiError(error, mockNewData, 'new-endpoint');
     }
   };
   ```

2. Create mock data in mockData.js:
   ```javascript
   export const mockNewData = { /* mock structure */ };
   ```

3. Use in component:
   ```javascript
   import { getNewData } from '../services/api';
   
   useEffect(() => {
     const fetchData = async () => {
       const data = await getNewData();
       setData(data);
     };
     fetchData();
   }, []);
   ```

ADDING A NEW SCENARIO
---------------------
1. Edit scenarioData.js:
   ```javascript
   export const SCENARIO_MOCKS = {
     // ... existing scenarios
     4: {
       time: '...',
       shipPosition: [...],
       riskAssessment: { ... },
       // ... complete scenario data
     }
   };
   ```

2. Update scenario count in useScenario hook
3. Add scenario indicator in TimelineControl
4. Test scenario transition

================================================================================
TROUBLESHOOTING
================================================================================

PORT ALREADY IN USE
-------------------
Error: Port 3000 is already in use

Solution:
1. Find process using port:
   ```bash
   lsof -i :3000          # macOS/Linux
   netstat -ano | findstr :3000  # Windows
   ```
2. Kill process or use different port:
   ```bash
   npm run dev -- --port 3001
   ```

MODULE NOT FOUND
----------------
Error: Cannot find module 'module-name'

Solution:
```bash
npm install
```

Or install specific module:
```bash
npm install module-name
```

LEAFLET CSS NOT LOADING
------------------------
Symptom: Map tiles not displaying correctly

Solution:
Ensure Leaflet CSS is imported in index.html or main.tsx:
```html
<link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css" />
```

BUILD ERRORS
------------
If build fails:
1. Clear cache: rm -rf node_modules
2. Reinstall: npm install
3. Try clean build: npm run build

RUNTIME ERRORS
--------------
Check browser console for error messages
Common issues:
- Missing prop types
- Undefined variables
- API connection failures (should fallback to mock data)
