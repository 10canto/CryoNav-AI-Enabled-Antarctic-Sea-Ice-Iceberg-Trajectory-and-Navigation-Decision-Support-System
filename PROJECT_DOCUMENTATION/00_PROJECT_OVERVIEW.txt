================================================================================
                     CRYONAV AI - PROJECT OVERVIEW
================================================================================

PROJECT NAME:
CryoNav AI - Antarctic Sea Ice, Iceberg Trajectory & Navigation Decision 
Support System

PROJECT DESCRIPTION:
CryoNav AI is an advanced AI-powered maritime navigation dashboard prototype 
designed for ice-strengthened polar research vessels traversing the treacherous 
corridor from Chennai Port, India to Maitri Research Station in Antarctica.

The system continuously fuses satellite-detected sea ice concentration zones, 
radar-tracked tabular iceberg drift vectors, high-latitude katabatic wind fields, 
and bathymetric chokepoints to dynamically calculate and evaluate 3 comparative 
polar routes.

================================================================================
EXPEDITION PROFILE
================================================================================

Departure Point:      Chennai Port, India (13.0827°N, 80.2707°E)
Destination:          Maitri Research Station, Antarctica (70.7644°S, 11.7386°E)
Vessel Class:         Ice-strengthened Polar Research Vessel (Polar Class 1A/PC5)
Total Distance:       10,500 – 12,750 km (~5,670 – 6,880 nautical miles)
Voyage Duration:      28 – 36 days (672 – 864 hours)
Transit Route:        Bay of Bengal → Central Indian Ocean → Roaring Forties (40°S)
                      → Furious Fifties (50°S) → Screaming Sixties (60°S) 
                      → Lazarev Ice Shelf

================================================================================
PROJECT OBJECTIVES
================================================================================

1. REAL-TIME MONITORING
   - Track ship position and environmental conditions
   - Monitor sea ice concentration and coverage
   - Detect and track tabular icebergs
   - Display wind patterns and ocean currents

2. RISK ASSESSMENT
   - Calculate collision risk with icebergs
   - Assess ice concentration hazards
   - Monitor weather conditions (wind, temperature, visibility)
   - Provide real-time risk level indicators (SAFE, CAUTION, WARNING, EMERGENCY)

3. ROUTE OPTIMIZATION
   - Generate and compare 3 navigation routes:
     * Route A: Safest (Ice-Avoidance Priority)
     * Route B: Fastest (Direct Southern Great-Circle Track)
     * Route C: Fuel-Saver (Current & Wind Assisted)
   - Calculate distance, time, fuel consumption, and risk for each route

4. AI-POWERED DECISION SUPPORT
   - Provide AI-generated route recommendations
   - Explain reasoning behind recommendations
   - Adapt to changing conditions dynamically

5. EMERGENCY ALERTING
   - Trigger visual and audio alerts for dangerous conditions
   - Display emergency modals with critical information
   - Provide actionable recommendations during crises

KEY FEATURES IMPLEMENTED
================================================================================

1. INTERACTIVE MAP VISUALIZATION
   - Real-time Antarctic map using Leaflet
   - Ship position marker with heading indicator
   - Iceberg markers with size and drift information
   - Ice zone overlays with concentration levels
   - Route polylines (solid, dashed, dotted styles)
   - Trajectory prediction lines for icebergs
   - Wind arrow indicators

2. COMPREHENSIVE DASHBOARD PANELS
   - Header bar with logo and scenario controls
   - Voyage information panel (distance, time, fuel)
   - Risk status panel with real-time metrics
   - Route options panel with comparison
   - Timeline control for scenario progression
   - AI explanation panel with recommendations

3. SCENARIO SIMULATION ENGINE
   - 4 operational scenarios modeling different expedition phases:
     * Scenario 0: Baseline departure & nominal transit
     * Scenario 1: Tabular iceberg detection in Iceberg Alley
     * Scenario 2: Gale-force Southern Ocean cyclone
     * Scenario 3: Catastrophic ice shelf calving event
   - Smooth transitions between scenarios
   - Dynamic data updates

4. REAL-TIME DATA INTEGRATION
   - API integration for backend connectivity
   - Mock data fallback system
   - Auto-detection of backend availability
   - Graceful degradation when offline

5. EMERGENCY ALERT SYSTEM
   - Visual alerts with color-coded status
   - Audio alerts with 3-beep pattern
   - Emergency modal with critical information
   - Route blockage indicators

6. RESPONSIVE DESIGN
   - Professional maritime-themed UI
   - Tailwind CSS styling
   - Mobile-responsive layout
   - Accessible color schemes

DEPLOYMENT & RUNTIME

- Backend expected at: http://localhost:8000

- All API endpoints prefixed with /api/
