CORE APPLICATION COMPONENT
================================================================================

APP.JSX
-------
Location: src/App.jsx
Purpose: Root application component that orchestrates the entire dashboard

State Managed:
- selectedRoute: Currently selected navigation route
- showRouteDetails: Boolean for route details modal
- showEmergencyAlert: Boolean for emergency alert modal  
- showSuccessModal: Boolean for journey completion modal
- navigationData: Complete data for current scenario
- isLoading: Loading state during data fetch
- notification: Toast notification messages

Key Responsibilities:
1. Fetch navigation data from API/mock service
2. Manage scenario progression using useScenario hook
3. Coordinate modal display logic
4. Pass data down to all child components
5. Handle route selection
6. Manage emergency alert triggers
7. Orchestrate polling with usePolling hook

Props Passed to Children:
- Map components: routes, icebergs, shipPosition, selectedRoute, wind data
- Panels: voyage info, risk assessment, routes, explanations
- Modals: alert data, success conditions
- Controls: scenario handlers, selected route handlers

ROUTEOPTIONSPANEL.JSX
---------------------
Purpose: Display and compare 3 navigation routes

Props:
- routes: Array of route objects
- selectedRoute: Currently selected route ID
- onSelectRoute: Callback when route is selected

Route Object Structure:
{
  id: 'safest' | 'fastest' | 'fuel',
  name: String,
  type: String,
  color: Hex color,
  style: 'solid' | 'dashed' | 'dotted',

  timeDays: Number,
  fuelLiters: Number,

  stars: Number (1-5),

  isFastest: Boolean,
  isCheapest: Boolean

Features:
- Three route cards in grid layout
- Star rating (⭐) based on safety
- Route badges (SAFEST, FASTEST, CHEAPEST)
- Select button for each route
- View Details button
- Visual highlighting of selected route
- [BLOCKED] indicator for impassable routes (Scenario 3)

Visual Elements:
- Color-coded route indicator bars
- Metric icons and values
- Responsive card layout

Features:

- Map attribution

  1. Base map tiles
  2. Ice zones (lowest)
  3. Wind arrows
  4. Route lines
  5. Trajectory lines
  6. Icebergs
  7. Ship marker (topmost)

================================================================================
COMPONENT INTERACTION PATTERNS
================================================================================

PARENT-CHILD COMMUNICATION:
- Props down: Data flows from App to children
- Callbacks up: Events bubble from children to App

SIBLING COMMUNICATION:
- Through parent component (App)
- Shared state lifted to App
- No direct sibling messaging

MODAL MANAGEMENT:
- Controlled by App state
- Boolean flags for each modal
- Overlay backdrop
- Focus trap on open

MAP SYNCHRONIZATION:
- All map layers share same Leaflet instance
- Coordinate system consistency
- Z-index ordering for proper layering
